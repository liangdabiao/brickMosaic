# Custom Brick Mosaic Generator - 自定义乐高马赛克生成器

[English](README.md) | 中文

## 项目简介

这是一个**100%客户端运行**的开源网络应用，可以将你自己的图片转换成乐高(LEGO)积木马赛克拼贴图，并生成可下载的PDF拼搭说明书。你可以使用现有的乐高Art系列套装来拼搭出完全自定义的马赛克作品。

**核心特点：**
- 🎨 从任意图片生成乐高积木马赛克
- 🔒 **隐私保护**：所有计算都在你的浏览器中完成，图片不会上传到任何服务器
- 📄 自动生成带分区指导的PDF拼搭说明书
- 🧩 支持组合多个乐高Art系列套装来获得更大尺寸的马赛克
- ✂️ 支持图片裁切、色彩调整等预处理
- 🆓 完全免费开源

在线使用：https://custombrickmosaic.github.io/

## 工作原理

### 整体流程

```
用户上传图片 → 图片预处理 → 色彩调整 → 算法分配积木 → 生成预览 → 生成PDF说明书
```

### 核心算法

整个马赛克生成分为两个阶段：

#### 第一阶段：初始分配

1. **调整尺寸**：将输入图片重新缩放至马赛克目标尺寸（宽 × 高 颗粒度）
2. **添加噪声**：在原始颜色值中加入微小随机噪声，以打破颜色相等的情况，避免算法卡住
3. **颜色匹配**：将每个像素的颜色与你选择的乐高套装中所有可用颜色进行比较，计算**颜色距离**（RGB空间中的平方欧氏距离）
4. **贪心分配**：按像素逐个分配最匹配的可用颜色，每分配一个颗粒，对应颜色的可用数量减1。如果最佳颜色已用完，则选择下一个最佳匹配颜色

> 作者测试过多种颜色空间（如CIE LAB），发现RGB空间已经能获得很好的效果。CIE LAB版本代码目前保留但被注释掉了。

#### 第二阶段：优化交换

初始分配完成后，算法进入优化阶段：
- 迭代尝试交换两个不同像素之间的积木颗粒
- 如果交换后**总体颜色匹配度**变好（总色差更小），则保留交换
- 重复这个过程，直到无法再通过交换改善结果
- 这个"暴力"交换过程能显著提升最终效果，但对于大尺寸马赛克需要较长计算时间

### 颜色匹配原理

颜色距离计算公式（RGB空间）：

```
distance = (r1 - r2)² + (g1 - g2)² + (b1 - b2)²
```

distance越小，颜色越接近。

## 详细操作步骤

### 步骤1：选择源图片
1. 点击"1. Choose a source image"下的文件选择框
2. 从你的电脑或手机中选择一张图片
3. 图片加载后会显示预览缩略图
4. 选择裁切方式（裁切中心/缩放到适应）
5. （可选）根据需要调整色相、饱和度、明度、对比度
6. （可选）如果图片有黑色背景，勾选"Ignore black regions in image"

### 步骤2：选择马赛克尺寸
1. 通过加减按钮调整马赛克的宽度和高度（单位：乐高颗粒/studs）
2. 查看下方显示的"Required parts"，这是你总共需要的颗粒数量
3. 一个标准乐高Art套装是48×48=2304颗粒

### 步骤3：选择你拥有的乐高Art套装
1. 在列表中找到你拥有的套装，通过加减按钮设置你要使用的数量
2. 每个套装包含不同的颜色和颗粒数量，程序会自动计算总可用颗粒
3. 查看右下角"Available parts"显示的总可用颗粒数
4. **注意**：必须保证可用颗粒数 ≥ 所需颗粒数，才能进行计算

### 步骤4：计算马赛克
1. 点击"Calculate mosaic"按钮开始计算
2. 进度条会显示计算进度
3. 等待计算完成，右侧会显示马赛克预览图

### 步骤5：下载拼搭说明书
1. 计算完成后，点击"Download instructions (pdf)"按钮
2. 程序会生成PDF文件并自动下载
3. 使用PDF阅读器打开，按照说明书拼搭即可

### 左侧控制面板

#### 第一部分：选择源图片（Step 1）

**文件选择框**
```
1. Choose a source image (It is not uploaded)
[选择文件...]
```
- **功能**：从本地设备选择图片文件
- **重要提示**：括号中的"It is not uploaded"表示图片不会被上传到任何服务器，所有处理都在本地进行
- **支持格式**：所有浏览器支持的图片格式（JPG、PNG、GIF等）

**图片预览区**
- 加载图片后显示缩略图预览
- 会实时显示你调整后的效果

**裁切/缩放按钮组**
```
[Crop center] [Resize to fit]
```

- **Crop center（裁切中心）**：保持原图宽高比，只裁切中心区域适应目标尺寸
- **Resize to fit（缩放到适应）**：将整张图拉伸/缩放到目标尺寸，可能会改变宽高比
- **默认选中**：Crop center

**忽略黑色背景复选框**
```
☐ Ignore black regions in image
```
- **勾选后**：RGB值为(0,0,0)的纯黑色区域不会被分配积木，在说明书中用"?"标记，你可以用剩余颗粒自行填充
- **使用场景**：当主体位于黑色背景上时，勾选此选项可以让算法将有限的彩色颗粒用在主体上，获得更好效果
- **默认**：不勾选

**色相滑块**
```
Hue: 0  [====•====]  (-180 ~ +180)
```
- **功能**：调整整张图片的色相（整体颜色偏移）
- **取值范围**：-180 到 +180，0表示不调整
- **用途**：整体偏色调整，让图片颜色更接近乐高现有颜色

**饱和度滑块**
```
Saturation: 0  [====•====]  (-100 ~ +100)
```
- **功能**：调整图片色彩饱和度
- **取值范围**：-100 到 +100，0表示不调整
- **用途**：降低饱和度可以让图片更依赖亮度差异，有时能获得更好效果

**明度滑块**
```
Value: 0  [====•====]  (-100 ~ +100)
```
- **功能**：调整图片亮度（明度）
- **取值范围**：-100 到 +100，0表示不调整
- **用途**：将图片整体亮度调整到乐高颜色覆盖范围内

**对比度滑块**
```
Contrast: 0  [====•====]  (-100 ~ +100)
```
- **功能**：调整图片对比度
- **取值范围**：-100 到 +100，0表示不调整
- **用途**：增加对比度让明暗差异更明显，减少对比度让过渡更平滑

#### 第三部分：选择拥有的乐高Art套装（Step 3）

每个套装的格式：
```

```

- **颜色指示**：红色表示可用颗粒不足，黑色表示足够
- **要求**：必须 Available ≥ Required 才能开始计算

## 使用技巧

### 输入图片选择
- **好的对比度**是获得好结果的关键
- 选择颜色分布与你拥有的套装相近的图片
- 尝试不同的裁切和缩放，多试几张
- 均匀纯色背景效果更好，可以先用图像处理软件将背景换成纯色

### 颜色调整技巧
- **多试不同滑块组合**，看看调整后对结果的影响
- 使用色相滑块让整体颜色更接近乐高现有颜色
- 有时降低饱和度能获得更好效果，这样算法会更依赖亮度差异
- 如果图片背景占很大空间，先用外部软件将背景设为纯黑(RGB 0,0,0)，然后勾选"Ignore black regions"，这样算法会把有限颜色用在主体上

### 套装选择
- 最终效果很大程度上取决于可用颜色，如果你还没有套装，可以多比较不同套装的颜色
- 可以组合多个不同套装来获得更丰富的颜色

### 颗粒限制的艺术效果
- 作者发现**刻意限制颗粒数量**能获得更有艺术感的结果
- 如果不限制颗粒数量，结果会显得平淡，缺乏色彩对比
- 限制颗粒数量会迫使算法使用次优颜色，反而增加了马赛克的色彩空间，看起来更有艺术感
- 技巧：输入小数如0.9来进一步限制每种颜色可用数量

### 多张图片
如果你想拼搭多个马赛克（并且拥有足够套装），建议：
1. 先用图像处理软件将多张图片拼接到一张大图
2. 相应调整马赛克总尺寸和套装数量
3. 让算法自由分配颗粒，这样能获得更好的整体效果

### 最后调整
生成说明书不代表必须完全按照说明书拼搭
- 拼搭完成后，你仍然可以交换个别颗粒来获得更满意的效果
- 这也是乐高拼搭的乐趣之一

## 本地运行

本项目是纯静态HTML+JavaScript应用，**无需构建过程**，无需任何依赖。

### 方法一：直接打开
1. 下载本项目到本地
2. 用浏览器直接打开 `index.html` 即可使用

### 方法二：使用本地HTTP服务器
```bash
# Python 3
python -m http.server 8000

# 然后访问 http://localhost:8000
```

```bash
# 使用npx serve
npx serve .
```

- jsPDF 1.5.3（PDF生成）

无需npm install，无需任何构建工具。

## 技术架构

- **语言**：原生JavaScript (ES6+)
- **图像处理**：HTML5 Canvas API
- **样式框架**：Bootstrap 5（CDN）
- **PDF生成**：jsPDF 1.5.3（CDN）
- **部署**：GitHub Pages 静态托管
- **计算**：全部在浏览器客户端完成，无后端服务器
